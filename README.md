</p>

<p>

</p>

<p>
👯 <b>Looking to collaborate on:</b><br>
Open-source web applications, real-time systems, and projects involving React, Node.js, or algorithmic problem-solving.
</p>

<p>

Designing scalable backend architectures, optimizing frontend performance, and gradually moving into system design concepts.
</p>
